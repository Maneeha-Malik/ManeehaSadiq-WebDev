## Features

* Fetches real user data from JSONPlaceholder API
* Displays users in a card layout with name, email and city
* Filters only users whose latitude (geo.lat) is less than 0
* Sorts users alphabetically by name
* Real-time search by username or email
* Show Details button reveals full address and company catchPhrase
* Only one user's details visible at a time
* Special gold styling for users whose zipcode starts with 5
* Shows "Failed to fetch users" if API fails
* Shows "No users found" if search has no results
